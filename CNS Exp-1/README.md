# Experiment 1 — Classical Ciphers

## Ciphers Implemented

| Cipher | File | Type |
|---|---|---|
| Caesar | `caesar_cipher.py` | Substitution |
| Vigenere | `vigenere_cipher.py` | Polyalphabetic |
| Rail Fence | `rail_fence_cipher.py` | Transposition |
| Monoalphabetic | `monoalphabetic_cipher.py` | Substitution |
| Frequency Analysis | `frequency_analysis.py` | Cryptanalysis |

## Usage

Run any cipher directly:
```bash
python caesar_cipher.py
python vigenere_cipher.py
python rail_fence_cipher.py
python monoalphabetic_cipher.py
python frequency_analysis.py
```

## Requirements
No external libraries needed — Python 3.x standard library only.
