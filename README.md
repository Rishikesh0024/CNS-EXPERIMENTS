# Experiment 1 — Classical Ciphers

## Ciphers Implemented

| Cipher | File | Type |
|---|---|---|
| Caesar | `Caesar/caesar_cipher.py` | Substitution |
| Vigenere | `Vigenere/vigenere_cipher.py` | Polyalphabetic |
| Rail Fence | `RailFence/rail_fence_cipher.py` | Transposition |
| Monoalphabetic | `Monoalphabetic/monoalphabetic_cipher.py` | Substitution |
| Frequency Analysis | `FrequencyAnalysis/frequency_analysis.py` | Cryptanalysis |

## Usage

Run any cipher directly:
```bash
python Caesar/caesar_cipher.py
python Vigenere/vigenere_cipher.py
python RailFence/rail_fence_cipher.py
python Monoalphabetic/monoalphabetic_cipher.py
python FrequencyAnalysis/frequency_analysis.py
```

## Requirements
No external libraries needed — Python 3.x standard library only.
